#029

Omnibar · Search scope

Find the work by its group name.

Bring open Chrome tab groups into omnibar search as first-class results, with enough context to choose the right window and a direct path back into the work.

Implementation checklist

0 of 8 complete

Behavior decisions

One group. One result. Clear destination.

  • Give groups a distinct result type, with the group title as the searchable and highlighted text.
  • Label each result with its parent window and member count, so same-named groups in different windows remain distinguishable.
  • When selected, prefer the group's current active tab; otherwise activate its earliest member by tab order.
  • If the group is collapsed, expand it before activating the chosen member so the destination is visible.

Scope boundary

Open groups only

Search the native groups returned by Chrome's tabGroups API. Closed or saved groups are outside this API-backed first version and should not be implied as searchable.
