# Tabby marketing

Run `pnpm marketing` from the workspace root. The [homepage](http://localhost:5182/) offers one labeled interactive demo, separate tabs/search/settings and color controls, and a rotating switch to the product video with music and captions. Header links open the corresponding face of that experience. The page speaks directly from Tabby’s maker, with standalone Manage tabs, Find anything, and Make it yours sections and dedicated illustrations rendered with the real tab manager, search, and appearance settings. A read-only [browser illustration](src/BrowserIllustration.tsx) has a 900 × 600 canvas that scales to fit smaller screens, showing the real tab manager on the left and search beneath the toolbar’s Tabby icon at the same time. The live demo starts with its first tab selected so accent changes are visible immediately. A sun/moon switch toggles dark mode. Reduced-motion preferences use an instant switch.

The homepage’s [feature illustrations](src/FeatureIllustrations.tsx) and browser view render the real [product experiences](../../packages/app/lib/index.ts) with static input. Always compose marketing product visuals from these shared components so they reflect the extension as it changes. [Demo resources](src/demo.ts) provide deterministic sample windows, tabs, bookmarks, history, and recently closed pages. Each demo owns its browser data, views, preferences, and playback. Refresh or Reset restores the samples; the app needs no Chrome permissions.

The header logo hops while visible and idle, taking turns with a shake of the Try it or Watch it sign. Both signs shake after each complete demo/video flip and continue their periodic cues while the switch has focus. The inline SVG banner cat squashes against its floor while scrolling down, lifts with wide eyes while scrolling up, and lands with a springy recovery. The privacy paws alternate full steps, keeping one foot planted against small scrolls, bounding travel between the section’s divider lines, and returning each foot in turn when scrolling stops. One quiet second after the pieces finish arriving, the seasonal playground starts individual shakes, spins, quick triple spins, and bounces with varied timing and speed, pausing after bursts of 3–5 movements and preserving the pieces’ stacking order. Drag or tap pieces to move them; holding for up to one second doubles the throw speed. The closing cat winks after a quiet pause, and a click or keyboard activation plays an uninterrupted wink and dismisses the automatic cue. The closing install button shakes periodically. Automatic cues pause during interaction, scrolling, or when hidden, and all motion respects reduced-motion preferences.

Use `pnpm test:marketing` for the headless browser workflows, `pnpm -F @extension/marketing type-check` for types, and `pnpm -F @extension/marketing build` for the standalone production app in `build/`.

## Hosting

The [Tabby marketing project](https://vercel.com/michael-drotars-projects/tabby-marketing) hosts the standalone app on Vercel. Its root directory is `pages/marketing`, with files outside that directory included so the shared workspace packages and brand assets are available. Use Node.js 22.x. [vercel.json](vercel.json) defines the frozen dependency install, preparation of the marketing app's dependencies, Vite build, and output directory. The root URL opens the homepage.

For a manual check, open the homepage at desktop and phone widths. On the homepage, switch between the hero demo and video, including through the header links; the sign, content, and switch text rotate together, and returning to the demo keeps your sample changes and pauses the video. Read the three feature sections and check their illustrations for clipping at phone widths. Check the full browser illustration: its side panel stays on the left, search stays open beneath the extension icon, and the frame keeps its 3:2 proportions as it scales down. Check the instant switch with reduced motion enabled. Try a window in the rail, select multiple tabs and use More actions, search for “design,” and switch themes and accents. The capture view offers guided-tour playback controls. Reset restores the demo. Videos start muted; enable music with the player's volume control and check that your choice persists when switching between the hero demo and video. Check captions and the Chrome Web Store links.

The [capture view](http://localhost:5182/?capture) provides the shared product tour at 960 × 720. With FFmpeg installed, run `TABBY_CAPTURE_MARKETING=1 pnpm -F @extension/e2e exec playwright test --config marketing.config.ts tour.spec.ts` to record the checked tour and update [the video](public/media/tabby-tour.webm) and [its poster](public/media/tour-poster.png). The capture combines the recording with [the soundtrack](public/media/tabby-tour-audio.ogg), which contains original instrumental music. Set `FFMPEG_PATH` to use a specific executable. [Captions](public/media/tabby-tour.vtt) describe its steps. Fonts are served locally with their licenses in [public/fonts](public/fonts).

Run the same browser workflows against a deployment with `TABBY_MARKETING_BASE_URL=https://your-deployment.vercel.app/ pnpm test:marketing`. The URL must end with a slash. Use `pnpm -F @extension/marketing exec vite preview --host 127.0.0.1 --port 5184` to serve the production build locally, then run the workflows with `TABBY_MARKETING_BASE_URL=http://127.0.0.1:5184/`.
