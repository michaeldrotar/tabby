# Release 1.3.0

**Version:** 1.3.0
**Release Date:** TBD

## Highlights

- **Batch Tab Actions**: Apply contextual actions to the complete selection from one shared ellipsis menu, including close, move, group, ungroup, pin, mute, reload, duplicate, copy, group management, and window actions.
- **Search in Chrome's Extension Popup**: Tabby Search opens in Chrome's standard extension popup from the toolbar or keyboard shortcut.
- **Numbered Window Switching**: Focus up to ten browser windows with Chrome shortcuts or by searching for their number in Tabby Search.
- **Tab Group Search**: Find Chrome tab groups directly in Tabby Search.

## Improvements

- **Selection Interactions**: Full support for multi-selection patterns:
  - First sidebar open selects the current window and its active tab
  - A plain window click selects that window, its tab groups, and its active tab; Shift/Cmd/Ctrl window selection includes all tabs in the selected windows
  - Click to select a single tab
  - Shift+Click to select a range of tabs
  - Cmd/Ctrl+Click to add or remove tabs, groups, and windows from selection
  - Cmd/Ctrl+A to select all tabs in the current window
  - Arrow keys navigate and select in default mode
  - Space enters multi-select mode for keyboard-only selection
  - Shift+Arrow extends selection range
  - Escape clears selection and exits multi-select mode
  - Right-click opens the shared action menu and preserves the current selection when the clicked item is already selected; the Context Menu key, Shift+F10, and Shift+Enter also open the focused item's menu. Right-clicking a window targets every tab in that window, while a plain left-click still targets its active tab
- **Open-Tab Search Modifiers**: Hold Cmd/Ctrl to open an open-tab result in a new tab or Shift to open it in a new window.
- **Keyboard Reordering**: Use Alt+Up/Down to move a focused tab or group.
- **Tab Status Indicators**: See loading, pinned, discarded, audible, duplicate, and recently accessed tab states in the list.
- **Shortcut Visibility**: The Tab Manager quick action shows its active Chrome shortcut, including custom shortcut assignments.
- **Selection-Aware Actions**: Available actions follow the selected tabs, windows, and groups. Cross-window grouping is disabled; rename is available only for exactly one selected group. Action labels count only the items targeted by that operation, and disabled reasons remain available in hover tooltips.
- **Action Bar Layout**: Icon counts for windows, groups, and tabs stay in a fixed-width notch and show `100+` above 99. All actions live in the ellipsis menu, which also opens when a row is right-clicked; its submenus keep Back fixed while actions scroll.
- **Action Feedback**: Major tab, group, and window actions report results and partial failures. Routine group expand/collapse actions stay silent, and the action menu remains available above notifications.

## Fixes

- **Search Focus Reliability**: Search now opens with focus consistently on every page, avoiding the cases where the previous in-page experience could fail to capture focus or fall back to a separate window.
