# Release 1.3.0

**Version:** 1.3.0
**Release Date:** TBD

## Highlights

- **Multi-Selection in Tab Manager**: Select multiple tabs at once using familiar keyboard and mouse patterns, laying the groundwork for bulk actions in future releases.
- **Reliable Search Popup**: Search tabs, bookmarks, and history from Chrome's standard extension popup, available from the Tabby toolbar icon or the `Cmd/Ctrl+E` shortcut.

## Improvements

- **Selection Interactions**: Full support for multi-selection patterns:
  - Click to select a single tab
  - Shift+Click to select a range of tabs
  - Cmd/Ctrl+Click to add or remove individual tabs from selection
  - Cmd/Ctrl+A to select all tabs in the current window
  - Arrow keys navigate and select in default mode
  - Space enters multi-select mode for keyboard-only selection
  - Shift+Arrow extends selection range
  - Escape clears selection and exits multi-select mode
- **Search Discoverability**: The search popup's quick actions now show the Tab Manager shortcut, making the all-windows Tab Manager easier to discover.
- **Search Continuity**: The most recent search remains available when the popup is reopened.

## Fixes

- **Page Access Prompts**: Search no longer injects an interface into webpages or requires page-access permissions for its normal workflow.
