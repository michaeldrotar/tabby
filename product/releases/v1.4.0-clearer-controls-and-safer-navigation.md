# Clearer controls and safer navigation

**Version:** 1.4.0
**Release date:** 2026-10-14

This release makes it easier to select tabs across windows, clear duplicate pages, and get around with the keyboard. Large tab sessions feel more responsive, and routine actions finish quietly.

## What's New

### Try Tabby before installing

- Try Tabby on its homepage with simple tabs/search/settings and color controls, or flip the same area to a product video with optional music and captions; videos start muted.

### Select tabs without switching pages

Click a tab row to select it without leaving the page you're on. When you're ready to go to a tab, click its icon, double-click the row, or press Enter.

### Keep your selection across windows

Browse other windows in the tab manager while keeping your selected tabs. Select a window or group, then deselect individual tabs while keeping the rest selected. Press Escape to clear the full selection.

### Duplicate tab cleanup

Close duplicate tabs across all windows from a tab's action menu, while keeping the tab you chose.

### Keyboard navigation

Jump between parts of the tab manager with Tab, and use arrow keys to reach **New tab** and **New window**. In narrow panels, the sidebar moves out of the way when you navigate into the tab list.

### Shortcut help

Options now includes a guide to Tab manager keyboard shortcuts, so you can find the keys for navigation, selection, and organization in one place.

### Accessible search and settings

Screen readers announce search results and the selected item. Settings menus follow your preference for reduced animation.

### Responsive large tab sessions

Large tab lists stay responsive as you scroll, navigate, and update tabs. Large groups expand and collapse promptly, and search stays responsive as you type.

### Quieter action feedback

Routine tab actions finish quietly, so you can keep organizing without extra messages interrupting you.

### Reliable shortcuts and search

Chrome shortcuts open search and the tab manager in the window you triggered them from. Search explains when a destination cannot be opened and keeps your query so you can try again.

### Sharper Tabby icons

Tabby's icons stay sharp in Chrome's toolbar and extension list.
