# Clearer controls and safer navigation

**Version:** 1.4.0
**Release date:** Not submitted

## Improvements

- Navigate search with a labelled input, announced results, and clear keyboard selection for assistive technology.
- Use clearer sentence-case labels, named settings controls, and separate group selection and collapse buttons.
- Large tab lists defer offscreen rendering, and search reuses query matching work.
- Properly sized Tabby icons stay sharp in the toolbar and extension list.

## Fixes

- Keyboard shortcuts use the initiating window correctly after Chrome restarts the extension’s background worker.
- Unsupported search destinations show a useful error, and window activation messages are validated before they are applied.
