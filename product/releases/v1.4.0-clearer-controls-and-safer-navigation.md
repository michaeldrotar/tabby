# Clearer controls and safer navigation

**Version:** 1.4.0
**Release date:** Not submitted

## Improvements

- Select tabs across windows without activating them; click a favicon, double-click a tab, or press Enter to activate it, and press Escape to clear the full selection.
- Active tabs stand out across the full row, windows indicate contained selections, and tab and creation-item focus outlines remain fully visible.
- Selecting a window or group selects its children; toggling a child off clears its parent selection and keeps the other children selected.
- Tab moves between manager sections, arrows reach creation actions, and Options keeps a flat settings list with a direct link to seasonal icon choices.
- Choose a toolbar look for each holiday; Tabby switches automatically to the upcoming holiday’s selected look, with date controls for Easter and Thanksgiving and Off choices for each holiday.
- The Options page header uses the selected seasonal icon when one is active.
- Moving keyboard focus into tabs collapses the expanded window sidebar in narrow panels.
- More actions handles selected-tab operations, while keyboard controls reorder tabs and groups.
- Action notifications explain partial results and errors without confirming routine success; clipboard copies still confirm the otherwise invisible update.

- Navigate search with a labelled input, announced results, and clear keyboard selection for assistive technology.
- Use clearer sentence-case labels, named settings controls, and separate group selection and collapse buttons.
- Large tab lists defer offscreen rendering, and search reuses query matching work.
- Large tab groups expand and collapse promptly, and idle tab ages refresh only when their labels change.
- Tab manager avoids redrawing unchanged tabs: in a 200-tab data fixture, hover, focus, or a one-tab edit redraws one row; scrolling and unchanged age labels redraw none.
- Properly sized Tabby icons stay sharp in the toolbar and extension list.
- Close duplicate tabs across all windows while keeping the tab chosen from its context menu.

## Fixes

- Keyboard close actions apply to the full selection, and dismissing notifications returns focus to the action bar.

- Keyboard shortcuts use the initiating window correctly after Chrome restarts the extension’s background worker.
- Unsupported search destinations show a useful error, and window activation messages are validated before they are applied.
