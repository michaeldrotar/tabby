# More predictable search

**Version:** 1.7.1
**Release Date:** 2026-10-29

Fixes search priorities, recall of recent choices, and results shifting while a search stays open.

## Bug fixes

### Search priorities

Corrected search priorities to favor commands, open windows, groups, and tabs before opening new pages, while letting recent activity and search choices bring relevant results forward.

### Window results without duplicates

Ordinary searches match windows by their custom names, preventing automatic window titles from duplicating matching tabs. Explicit window commands still list every open window by number.

### Recall with shorter searches

Recent choices retain their priority when you shorten a search, type only the beginning of its words, or reorder the words.

### Return to pages already open

Returning to a recent search favors matching tabs opened or restored from its results, helping you get back to a page without opening another copy. The original destination remains prioritized if the tab no longer matches.

### Stable results

Results stay in place as time passes or unread counts change in otherwise equally ranked page titles.
