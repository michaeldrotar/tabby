# Release 1.8.0

**Version:** 1.8.0
**Release Date:** TBD

## What's New

### Clearer side panel instructions

Options now identifies the Chrome Panels setting that controls which side Tabby appears on.

### Easier shortcut setup

Options explains why shortcuts are edited in Chrome and guides you through changing Tabby’s shortcuts there.

### Find the right window icon

Make each window easy to recognize with an icon, emoji, monogram, uploaded image, or favicon. Switch between saved choices for each type, with one shared background color. Search over 1,600 icons and find emoji by name or keyword.

### Find named windows sooner

Your saved window names appear in search and the Tab Manager as soon as Tabby recognizes them, while Chrome continues restoring other tabs. Names adjust as more windows return, using their order to help distinguish similar windows.
