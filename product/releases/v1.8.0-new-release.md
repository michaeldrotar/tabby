# Release 1.8.0

**Version:** 1.8.0
**Release Date:** TBD

## What's New

### Group tabs across windows

Add tabs to an existing group in another window directly from the group menu.

### Steady context menus

Submenus keep the main menu’s width and opening direction, with longer lists scrolling within its original height. Going back returns the main menu to its original position.

### Move tabs without leaving your window

Move tabs and groups between windows while keeping your place. Hold Shift when moving to switch to the destination instead.

### Close search with a click

Use the X button to close search with your mouse, keeping your query for next time.

### Clearer side panel instructions

An illustrated guide in Options points out the Chrome Panels setting that controls which side Tabby appears on.

### Easier shortcut setup

Options briefly explains why shortcuts are edited in Chrome, with an illustrated guide pointing to the edit control.

### Simpler global shortcuts

Global shortcut settings focus on opening Tabby search and the tab manager. Switch to a window by searching for its name in Tabby.

### Reach search actions with arrow keys

Use the arrow keys from an empty search to select Open tab manager and Open options. Press Enter to open the selected action, or keep typing to search.

### See group counts for each window

See how many tab groups are in each window alongside its tab count.

### Find the right window icon

Make each window easy to recognize with an icon, emoji, monogram, uploaded image, or favicon. Switch between saved choices for each type, with one shared background color. Search over 1,600 icons and find emoji by name or keyword.

### Act on tabs from the keyboard

Pin, mute, duplicate, reload, group, ungroup, move, copy, and discard tabs with single-key shortcuts in the Tab Manager, or create a new tab below the focused tab. Apply actions to your selection without opening a menu. Shortcut keys also work from the open actions menu. See the keys beside actions, or find the full list in Options. Keyboard choosers open beside the focused item.

### Unpin tabs from the pin indicator

Unpin a tab directly from its pin indicator. A crossed-out pin previews the action on hover, and keyboard navigation reaches the pin button.

### Quick hints for tab actions

The pin and close buttons show quick “Unpin” and “Close” hints.

### Recognize duplicate tabs

Duplicate tabs have a labeled badge that stays visually distinct from the action buttons.

### Clear up duplicate tabs

The duplicate cleanup action uses “Remove” and a brush icon to make its purpose clearer.

### Simpler tab rows

Tab rows show the page title and site without confusing activity times.

### Know what you’re copying

Copy actions name titles and URLs and show how many items will be copied, making them easier to distinguish from duplicating tabs. Confirmations tell you which text reached your clipboard.

### Get back to your tabs easily

Return from window editing or switching with a Back to tabs arrow in the header, even in short panels. Back eases into place while the window icon stays visible.

### Restore your window customizations

Reset shows a window’s default name, icon, and color while keeping its custom choices. Reopen the editor to restore its name, color, and saved icon, emoji, monogram, image, and favicon. Your first edit also prepares a random emoji, initials from the name, and a favicon that stays saved when the active tab changes.

### Search one window or choose a source

Search from the Tab Manager starts with tabs in the current window. Browse recent tabs and pages before typing, or focus on windows, tab groups, bookmarks, history, closed pages, and commands. Use Tab to change scope while keeping your search text. If a scope has no matches, broaden your search without retyping. An unfinished search restores its text and scope together; a fresh search starts with All.

## Fixes

- Closing a tab from its actions menu keeps keyboard focus in the tab list. Menus dismiss when their window closes.

- Tab and Shift+Tab follow a consistent path through window controls, tab and window lists, and the New tab and New window buttons.
- Keyboard focus is easier to distinguish from selected window colors and icons.
- Saved window names appear sooner while Chrome restores tabs and stay matched as more windows return.
