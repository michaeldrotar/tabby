# Batch Actions and Smarter Search

**Version:** 1.3.0
**Release Date:** TBD

This release makes it easier to work across tabs, groups, and windows. Select multiple items and apply actions to the full selection from a shared menu. Tabby Search now works more consistently across pages and adds new ways to open copies of open tabs and switch between windows.

## What's New

### Batch Actions

Select multiple tabs, groups, or windows, then perform actions across the selection from one shared menu.

### Search in the Extension Popup

Tabby Search now opens in Chrome's standard extension popup from the toolbar or keyboard shortcut. This fixes inconsistent focus across pages and reduces the permissions Tabby needs.

### Open Tabs from Search

Search Chrome tab groups by name. From Tabby Search, hold Cmd/Ctrl to open a copy of an already-open tab in a new tab, or Shift to open a copy in a new window.

### Chrome Window Shortcuts

Assign Chrome shortcuts to focus any of your first ten windows, or search by number in Tabby Search.

### Manual Tab Discard

Discard eligible inactive tabs from a selection in one action, with an action count that reflects eligible tabs and confirmation that reports successful discards. Chrome reloads a discarded tab when you activate it again.

### Keyboard Reordering

Move focused tabs and groups with Alt+Up/Down.

### Create Tabs and Windows

Create and focus tabs in the viewed window or a tab group, and open new windows from the window list.

### Sidebar Layout

In narrow panels, the expanded sidebar overlays the tab pane and action bar without showing content through it.

### Tab Status and Shortcut Details

See loading, pinned, discarded, audible, duplicate, and recently accessed states in the Tab Manager. Its quick action also shows the active Chrome shortcut.
