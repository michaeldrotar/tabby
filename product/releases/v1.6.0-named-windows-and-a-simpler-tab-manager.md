# Named windows and a simpler Tab Manager

**Version:** 1.6.0
**Release Date:** 2026-10-17

## What's New

### Name your windows

Give each window a custom name, icon, and color so it's easy to recognize. Names appear in search and when moving tabs between windows. Search for a window by name to switch straight to it.

### One window, one clear view

The Tab Manager now shows one window at a time in a single pane, giving your tabs more room. Switch, create, and close windows from the new header.

### Stay in context

Choosing a window now brings it forward and opens its Tab Manager. Clicking a tab switches to it, keeping the sidebar in sync with what you're viewing.

### Improved keyboard controls

Move between the window header, tabs, and tools with the arrow keys.
