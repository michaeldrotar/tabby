# Named windows and a simpler Tab Manager

**Version:** 1.6.0
**Release Date:** TBD

## What's New

### Name your project windows

Choose active-tab or first-tab defaults in Settings, or use the header pencil to give a window a custom name, icon, and color. Reset returns that window to the global default. Changes save immediately, and custom names appear in search and move destinations. Search a custom window name in the omnibar and choose its Window result to focus it without changing its active tab. Window results have a base search priority below commands and above tabs. Names stay on your device, with matching to recognize reliably restored windows.

### One window, one clear view

Choose a window in the animated switcher to bring it forward and open its Tab Manager. The picker opens scrolled to the current window, with controls to create and close windows. Each window keeps its own selection and editor state.

### Keep selection in context

Click a tab to select and activate it. Cmd/Ctrl-click toggles selection and Shift-click selects a range without activating. The active tab starts selected, and Escape restores that selection. Select groups or individual members, and see each action's affected tab count. Use Ctrl+A or Cmd+A to select all tabs and groups, including collapsed groups. Right-click opens actions up to 20 pixels to the right of the cursor; click actions to show their options in place. Right-click another item to transition to its menu; click More actions to toggle it. Move and group menus list existing destinations first, with separate + New window and + New group actions at the bottom. An empty action menu shows a larger square prompt with an icon. Complete groups retain their identity during moves.

### Keep everyday tools within reach

Search and Settings stay at the bottom left, with More actions at the bottom right. New tab stays with the tabs, and New window sits at the end of the window picker. Window close buttons follow tab close buttons, appearing on hover or keyboard focus and staying visible for the current window.

### Follow focus through the manager

Use Up and Down to move between the window header, tab list, and bottom tools. Left and Right move between header controls or bottom tools. Keyboard context menus open beside the focused item. Closing a menu with Escape returns focus to the control used before opening it.
